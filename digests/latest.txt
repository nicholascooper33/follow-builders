The MAD Podcast with Matt Turck
How to Build Long-Horizon AI Agents — Mitch Troyanovsky, Basis
https://www.youtube.com/@DataDrivenNYC/videos

Takeaway: Building agents that reliably run for hours or days requires rethinking everything from evals to context management — and the English you give an agent matters more than the code underneath it.

Mitch Trojanovsky is the co-founder of Basis, a unicorn company building autonomous accounting agents. Its agents complete entire tax returns end-to-end — running for hours, sometimes days — and the episode is a true reference conversation on what it takes to make long-horizon agents actually work in production.

The conversation opens with an unusual detail: everyone at Basis whispers to AI through microphones all day. The reason gets at something fundamental. "You need to give it as much context as possible because it by definition is always missing context in some way," Mitch explains. "Speaking is just so much faster than writing things down... To an agent, they don't care. They'd actually prefer it."

On evals, Mitch pushes back on a common assumption: passing 100 evals doesn't mean your agent is production-ready. "Even if you got it right 100 out of 100 times, if a person is just getting it right because they're going to Wikipedia, the accounting firm wouldn't hire them, and so they shouldn't hire us either." Process fidelity matters as much as outcome accuracy.

One of the sharpest insights in the episode: "You'll see people freaking out over a code file that isn't abstracted properly, and yet their context is total sh*t. The English is more precious because the English affects the performance. The code does not affect the performance." Context is runtime training data — and most builders underweight it relative to their code.

The episode also covers behavior specs (structured rules governing how agents should act), ontologies (building structured worlds for agents to operate in), why reasoning models like o1 and o3 were the unlock for long-horizon agents, what AutoGPT got wrong, and an open-source collaboration with BrainTrust around behavior spec frameworks. Mitch closes with a view on durable moats: they're not technical infrastructure. The episode is broad and specific in equal measure — worth the full listen.

Claude Blog
Building intelligent apps for Apple platforms with Claude in the Foundation Models framework
https://claude.com/blog/claude-for-foundation-models

Anthropic released a Swift package that connects Claude to Apple's Foundation Models framework, letting Apple developers blend on-device and cloud intelligence in the same app. The architecture is layered: Apple's on-device models handle fast local tasks (summarization, extraction), and Claude takes over when multi-step reasoning, code generation, or live web search is needed. Because Apple's framework returns typed Swift values via @Generable annotations, developers arrive at the Claude API call with clean, structured inputs instead of raw user text. Compatible with iOS 27, iPadOS 27, macOS 27, visionOS 27, and watchOS 27. A representative example: a journaling app generates daily prompts on-device, then hands off to Claude when the user asks for patterns across months of entries — one seamless experience, two models doing what each does best.
