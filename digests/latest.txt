AI & I by Every — "Inside Stainless: The Developer Tools Startup Anthropic Just Bought for $300 Million"
https://www.youtube.com/playlist?list=PLuMcoKK9mKgHtW_o9h5sGO2vXrffKHwJL

Takeaway: MCP is the emerging interface layer connecting AI to the internet — but building MCP servers that actually work requires deep product and engineering discipline, and the future likely belongs to code execution as a "super tool" that replaces hundreds of individual MCP endpoints.

Alex Rattray, founder and CEO of Stainless, joined Dan Shipper on AI & I to unpack what his company does and why Anthropic paid a reported $300 million for it. Stainless builds the APIs and SDKs powering the developer infrastructure of major AI companies — including OpenAI and Anthropic — and has been expanding aggressively into MCP servers.

The core insight of the episode is that MCP, while promising, is genuinely hard to scale. Models can only handle a limited number of tools before context windows overflow and performance collapses. A large API like Stripe has hundreds of endpoints — directly translating those into MCP tools would consume the entire context budget before a single task is attempted. Rattray's design principles for reliable MCP servers: keep the tool count small, give each tool a precise and specific name and description, minimize input and output parameters, and use JSON filters (like JQ) to strip unnecessary data from responses. For larger APIs, Stainless uses a "dynamic mode" with just three tools — list endpoints, learn about a specific one, and execute it — which keeps context manageable at the cost of additional round trips to the model.

The bigger vision Rattray shared is that MCP tool lists will eventually give way to a code execution "super tool." Instead of exposing hundreds of API endpoints, the AI writes TypeScript or Python against an SDK, a sandboxed server runs it, and a type-checker catches hallucinated endpoints before they cause failures. "The context hit coming back from all of this is going to be like 10 lines of text," he said. This approach keeps context minimal and dramatically speeds up multi-step operations — with the bonus that one-off AI actions can be committed to a repo and turned into permanent production software.

Rattray also described how he uses MCP today in his own work: connecting Notion, HubSpot, Gong, and a read-only copy of Stainless's database so he can ask questions like "What are the interesting customers that signed up last week?" — with the AI querying across all those systems and synthesizing a summary. He also maintains a company knowledge base in a Git repo via Claude Code, storing customer quotes and refined SQL queries for future reuse. On security, his view is that restricting what's exposed through MCP is only a partial fix — the right layer for security is the API itself, via OAuth with granular scopes and permissions.
