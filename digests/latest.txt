PODCASTS

AI & I by Every — "Why We Switched From Claude Code to Codex"
https://www.youtube.com/watch?v=IDSAMqip6ms

Takeaway: Codex has quietly transformed from a senior-engineer-only pairing tool into the leading general-purpose agent desktop for knowledge workers — and Every's team has fully migrated.

Dan Shipper and Austin, Every's head of growth, hosted a live "Codex Camp" to walk subscribers through their switch from Claude Code to OpenAI's Codex desktop app. The conversation is bracingly honest: three months ago Codex "was trash." It was built for senior engineers, argued with users, lacked emotional intelligence, and was hobbled for safety inside a sandbox. But OpenAI pivoted hard after seeing how Claude Code was succeeding by being fast, smart, and emotionally aware on the desktop. The result is now what Austin describes as the best agent management interface available — faster, better organized, and capable of pulling in data from Gmail, Slack, Notion, and Stripe at startup.

Austin described his typical morning: "When I sign on during the day, Codex is the first thing I open. It is pulling in whatever I need from Gmail, Slack, Notion, Stripe, all of our data sources." He uses it to build automations, draft go-to-market plans, manage recruiting pipelines, and maintain a live KPI dashboard in Notion that updates every six hours across all of Every's data sources — work that previously required blocking off a full day or hiring a consultant.

Dan articulated the broader macro frame: there is now an open race among model companies — Anthropic (Claude Code / Claude Desktop), OpenAI (Codex), xAI (Cursor) — to own the "agent management interface." Each is building a desktop app that starts as a programming agent and expands to cover all knowledge work. Dan expects Anthropic to close the current gap within weeks or months, after which the two tools will trade the lead repeatedly.

A key workflow insight from Austin: he keeps a final review step outside the agent — reviewing Slack drafts in Slack, email drafts in Gmail — to preserve human accountability before anything reaches colleagues. He also built Compound Knowledge, a fork of the open-source Compound Engineering plugin, tuned for knowledge work: checking strategic alignment and data accuracy rather than security and front-end design. Sessions end with a prompt to compound learnings into shared memory and convert any useful workflow into a reusable skill.

Direct quote — Dan Shipper: "There's a new operating system for how and where you're gonna get your work done, and it's this kind of agent management interface."

BLOGS

Claude Blog — "New in Claude Managed Agents: dreaming, outcomes, and multiagent orchestration"
https://claude.com/blog/new-in-claude-managed-agents

Anthropic shipped three major updates to Claude Managed Agents. Dreaming is a new scheduled process that reviews past agent sessions and memory stores, extracts patterns, and curates memories so agents self-improve over time — with the developer choosing whether updates land automatically or go through human review first. Harvey used dreaming for complex legal drafting work and saw completion rates rise approximately 6x in tests; their agents now retain file-type workarounds and tool-specific patterns across sessions.

Outcomes lets developers write a rubric describing what success looks like; a separate grader evaluates each output in its own context window and sends the agent back for another pass if the bar isn't met. In testing, outcomes improved task success by up to 10 percentage points, with the largest gains on the hardest problems — and +8.4% on docx and +10.1% on pptx file generation in internal benchmarks. Spiral by Every uses outcomes to score every draft against Every's editorial principles and the user's voice before returning anything to the user. Wisedocs used it to run document quality checks 50% faster while staying aligned with internal standards.

Multiagent orchestration allows a lead agent to delegate pieces of a complex job to specialists running in parallel on a shared filesystem. The lead agent can check in with subagents mid-workflow because events are persistent and every agent tracks its own history. Netflix's platform team uses this to analyze logs from hundreds of builds simultaneously, surfacing only patterns that recur broadly rather than one-off anomalies. Every step is traceable in the Claude Console — which agent did what, in what order, and why.
