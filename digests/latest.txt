Peter Steinberger — Polyagentmorous ClawFather, co-creator of OpenClaw at OpenAI
Peter has wired Codex into his CI pipeline in an impressive loop: every commit that lands on main triggers a Codex instance that reviews the diff for regressions and security issues. If a problem is found, a new Codex spins up and (if still relevant) opens a PR with a fix — then a review agent checks that PR and can trigger up to 5 additional fix loops. Within 10 minutes of going live, the system caught one of his own bugs. This is one of the clearest examples yet of fully autonomous agent-driven code review in production.

Dan Shipper — CEO at Every, "the only subscription you need to stay at the edge of AI"
Dan is exploring a new category he's calling "agent-native" apps — software designed to be used inside the in-app browser of your coding agent (Codex, Cursor, etc.), where both the human and the AI share full context and can see what the other is doing. He demonstrated this with PostHog inside Codex: the agent can write analytics queries, view results, kick off sub-agents to write PRs, or run production DB queries — all without context switching. He sees this as a large opportunity for builders to rethink what software looks like when the primary user is a human-agent pair.

Aaron Levie — CEO at Box
Aaron pushed back firmly on "software jobs are disappearing" narratives with a detailed counter-argument: we are not dividing a fixed pie of software, we are about to see 100X more software than exists today. He points to legacy on-prem systems needing re-platforming, SMBs that could never afford developers, security backlogs, IT automation, and data integration — all requiring humans who can orchestrate agents, manage their output, and take ownership of the results. He also noted a distinction: agentic coding is great for shipping fast, but ongoing maintenance and security patching remain real costs that most knowledge workers aren't prepared for.
