Unsupervised Learning — "AI Vibe Check: Lab Wars, Why APIs Might Vanish & Future Predictions"
https://www.youtube.com/watch?v=W_iO8XxgD_I

Takeaway: The lab wars are shifting fast — Anthropic is on an unprecedented vibe run, open weights AI may be quietly contracting, and compute constraints could soon force labs to restrict or kill public API access entirely.

Host Jacob Efron (Redpoint investor) reunited with Ari (CEO, Datalogy, former DeepMind/Meta researcher) and Rob (Radical Ventures) for a wide-ranging episode covering the last six months in AI.

The most striking structural shift: engineers are becoming managers of agents, not individual contributors. Ari noted that at Datalogy, people now "context switch between managing different agents rather than just kind of working on the one thing." But this creates new bottlenecks — code review is now the chokepoint, and the team is reluctant to go fully to "my agent will review your agent's output."

On open weights, both guests converged on a bearish view. Meta appears to be pulling back from its open-source strategy. Chinese labs are keeping their best models proprietary behind APIs, only open-sourcing smaller, less performant versions. The economics don't support giving away weights once you've achieved frontier credibility. As Ari put it: "I think we probably hit the peak number of open models and it's now going to get less and less."

The spiciest prediction came from Ari: "There's a very reasonable chance that we see Anthropic, but it could be OpenAI, suspend API access for some period of time or otherwise heavily limit API access." Not as a business decision — purely due to compute constraints, with labs increasingly routing capacity to first-party products like Claude Code. "That is a huge existential threat to anybody that builds on top of these models."

On Anthropic's Fable restrictions for AI development use cases, Ari noted the community outrage wasn't about the restriction itself — it was the silence. "It doesn't say I'm not going to help you with this, it just does a poor job on that without you knowing." He called it competitive positioning dressed as safety, and observed that many loud AI voices on X would likely shift to Codex as a result — "a pretty nice gift for OpenAI."

Rob revised his robotics timeline: foundation models have crossed a commercial viability threshold in just the past few months, and as early deployments start spinning the data flywheel, he now believes a "GPT-3 moment" for general-purpose robotics AI is not far off. His year-end prediction: by end of 2026 it will be obvious Anthropic is becoming a force in life sciences — Dario has long been passionate about bio, and there are strong rumors of Anthropic setting up wet lab facilities to collect experimental data.

Anthropic Engineering: "An update on recent Claude Code quality reports"
https://www.anthropic.com/engineering/april-23-postmortem

A candid postmortem on three separate changes that caused Claude Code quality regressions between March and April 2026, all now resolved as of v2.1.116 (April 20). The three issues: (1) Reasoning effort was silently downgraded from high to medium on March 4 to reduce latency — users noticed and disliked it; reverted April 7. (2) A caching bug shipped March 26 was supposed to clear old thinking blocks once after an idle session, but instead cleared them on every subsequent turn, making Claude increasingly forgetful and draining usage limits faster than expected; fixed April 10. (3) A system prompt addition on April 16 — "keep text between tool calls to ≤25 words" — caused a 3% drop in coding quality; reverted April 20. As an apology, Anthropic reset usage limits for all subscribers. Going forward: broader eval suites for every system prompt change, wider soak periods, gradual rollouts, and tighter code review tooling.

Anthropic Engineering: "Scaling Managed Agents: Decoupling the brain from the hands"
https://www.anthropic.com/engineering/managed-agents

Anthropic's engineering blog explains the architecture behind Claude Managed Agents — a hosted service for long-horizon agentic tasks. The core design insight: decouple the "brain" (Claude + harness) from the "hands" (sandboxes and tools) and the "session" (the durable event log). In the old coupled design, a single container failure meant losing the entire session, and debugging required opening a shell inside a container holding user data. In the new architecture, each component can fail or be replaced independently — container failures are just tool-call errors that Claude can catch and retry, and harnesses are stateless so they can be rebooted from the session log at any time. Credentials are never exposed inside the sandbox: Git tokens are baked in at clone time; OAuth tokens are held in a secure vault and accessed via proxy. The performance gains were dramatic: p50 time-to-first-token dropped ~60%, p95 dropped over 90%. The design philosophy borrows from operating systems: "programs as yet unthought of" — stable interfaces, implementations that can evolve freely as models improve.

Claude Blog: "New in Claude Managed Agents: self-hosted sandboxes and MCP tunnels"
https://claude.com/blog/claude-managed-agents-updates

Two major additions to Claude Managed Agents announced May 19: self-hosted sandboxes (public beta) and MCP tunnels (research preview). With self-hosted sandboxes, enterprises can keep all tool execution — code runs, file edits, network calls — within their own infrastructure or with managed providers (Cloudflare, Daytona, Modal, Vercel), while orchestration and context management stay on Anthropic's side. MCP tunnels let agents reach private MCP servers inside a company's network via a lightweight gateway that requires only a single outbound connection — no inbound firewall rules, no public endpoints, traffic encrypted end to end. Early adopters include Amplitude (design agent for on-brand UI/marketing), Clay (GTM engineering agent Sculptor that builds and monitors workflows autonomously), and Rogo (finance analyst agent handling proprietary data securely).
