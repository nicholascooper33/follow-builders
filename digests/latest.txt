Peter Yang — Product at Roblox, runs Creators Collective newsletter (140K+ readers)
Peter shared a five-step framework for building AI skills that check their own work and improve over time: (1) give the skill examples of good output, (2) write a clear trigger description, (3) add an evals file with 10 pass/fail checks, (4) create a memory file to capture one-sentence learnings, and (5) build a "skill to edit skills" that removes stale or duplicate instructions. The compounding loop of skill + eval + memory is the key structural insight.

AI & I by Every — "The SaaS Apocalypse Is a Goldmine With Figma's Matt Colyer"
Published: 2026-06-03
https://www.youtube.com/watch?v=kYKebKB3-d0

Takeaway: The "SaaS apocalypse" is actually a gold mine — AI will expand the global developer population from ~30 million to a billion or more, creating dramatically more demand for software tools, not less.

Matt Colyer, Director of Product Management for Developers at Figma, joined Dan Shipper to push back on the SaaS doomsday narrative with a clear-eyed and practically grounded perspective. Matt's core argument: when the number of people who can build software grows by an order of magnitude, the demand for software infrastructure, design systems, and maintenance tooling explodes with it. Building your own vibe-coded app is fun until you have to maintain the SMTP server — at which point, you pay someone else to run it. As Matt put it: "If you're in that space, it means it's a gold mine."

The conversation went deep on what that means for Figma specifically. Matt described Figma's agent as designed to operate directly on the infinite canvas — enabling divergent brainstorming (generating multiple design directions in parallel frames) and convergent filtering (clustering and evaluating those options). He sees this as the antidote to the "text box rules" era: instead of a linear chat interface, agents act inside a spatial medium built for design iteration. Figma's MCP server handles the code-to-design direction (importing a live page into the Figma canvas for direct manipulation), while their Kit Design Context tool handles design-to-code (wrapping Figma components and guidelines for agents to generate faithful implementation branches).

Matt also described Figma's internal agent use: a product operations tool (PMOS) that aggregates org charts, Asana, Slack, and GitHub into a SQLite file system, then uses skills to auto-generate onboarding documents for new team members. The insight was that context already existed — it just needed to be shaped correctly for an agent to use it.

On the future of PMs and designers, Matt argued that curiosity is the differentiating trait. Foundations still matter ("you have to understand long division before you trust the calculator"), but the people who will build with these tools at the frontier are the ones pushing models to their limits, not just accepting the output. His closing analogy: LLMs are the Hitchhiker's Guide to the Galaxy — a magical time to be alive if you're the kind of person who keeps asking why.

Direct quote: "I think there's this incredible time that we're moving through of product development and really the democratization of technology. The end result is that there is dramatically more software out there in the world. If you're in that space, it means it's a gold mine."
